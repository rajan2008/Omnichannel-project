# Testing Documentation

This folder is dedicated to testing details, results, and notes for the project. Team members are encouraged to add their findings, Postman collections, and manual testing logs here.

## Structure
- `/unit`: Results for unit tests.
- `/e2e`: Results for end-to-end testing (Cypress/Playwright).
- `/manual`: Manual QA logs and screenshots.
- `team_notes.md`: Shared space for team members to add quick testing updates.

## How to contribute
1. Create a new markdown file or add to existing ones.
2. Use descriptive headers and dates.
3. If reporting a bug found during testing, include steps to reproduce.
